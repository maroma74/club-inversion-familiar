- **Primary Navy (Fondo principal / Textos oscuros):** `#0E2138` (hsl 215, 60%, 14%)
- **Navy Secondary (Superficies dark / Tarjetas):** `#162E4A`
- **Growth Emerald (Acento principal / Éxito / CTA):** `#10B981` (hsl 159, 84%, 39%)
- **Growth Light (Gradientes y detalles):** `#34D399`
- **Trophy Amber / Gold (Competición / Gamificación):** `#E5A016` (hsl 39, 86%, 49%)
- **Surface Light (Fondo claro / Dashboard light):** `#F8FAFC`
- **Slate Secondary (Bordes / Textos muteados):** `#64748B` / `#94A3B8`
