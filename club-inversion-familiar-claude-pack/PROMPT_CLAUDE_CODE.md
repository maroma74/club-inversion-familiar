# Instrucción Inicial para Claude Code

Copia y pega la siguiente instrucción directamente en la terminal de Claude Code:

---

Hola Claude. Necesito que inicialices y desarrolles la aplicación web para **Clubdeinversionfamiliar.com** a partir de los documentos incluidos en este repositorio:
1. Revisa `CLAUDE.md`, `docs/brand-guidelines.md` y `docs/technical-specs.md`.
2. Utiliza el stack Next.js (App Router), TypeScript, Tailwind CSS y Lucide Icons. Configura los tokens de color del tema según la paleta corporativa (`#0E2138`, `#10B981`, `#E5A016`).
3. Integra los componentes SVG del logo y favicon ubicados en `assets/`.
4. Desarrolla las pantallas funcionales principales:
   - Dashboard familiar con Leaderboard (ranking mensual/anual de rentabilidad).
   - Módulo de Asignaciones Mensuales (donde los padres dotan el saldo y los hijos lo distribuyen).
   - Catálogo interactivo de Carteras Propuestas (con distribución porcentual, nivel de riesgo y tesis de inversión didáctica).
5. Deja preparada la estructura modular de base de datos con las tablas y políticas descritas en `technical-specs.md`.
Procede paso a paso verificando la compilación y asegurando una UI limpia, moderna y gamificada para toda la familia.
